Test Video Input

Generate test patterns to validate your streaming server

SRT (Secure Reliable Transport): Low-latency protocol ideal for streaming over unreliable networks.
RTSP (Real Time Streaming Protocol): Standard protocol for IP cameras and professional streaming.
RTSP-UDP: RTSP with UDP transport for lower latency (less reliable).
Test pattern will be pushed and automatically available on all protocols (RTSP/WebRTC).

0 = continuous (runs until stopped), max 3600
Elapsed: 00:00

Viewing Test Streams

RTSP (TCP): rtsp://localhost:8554/[stream-name]

RTSP (UDP): rtsp://localhost:8554/[stream-name] (specify UDP in player)

SRT: srt://localhost:8890?streamid=read:[stream-name]

Use VLC or FFplay to view:

ffplay rtsp://localhost:8554/test-input (TCP)

ffplay -rtsp_transport udp rtsp://localhost:8554/test-input (UDP)
